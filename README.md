# ApiPostgresConnector

REST API коннектор для подключения к PostgreSQL базе данных.

## Описание

ApiPostgresConnector предоставляет REST API интерфейс для работы с базой данных PostgreSQL из любых приложений. Десктопное приложение с GUI интерфейсом на CustomTkinter и встроенным Flask API сервером.

## Возможности

- 🌐 REST API для выполнения запросов к PostgreSQL
- 🖥️ GUI интерфейс настроек (CustomTkinter)
- 🔌 DSN подключение — ввод строки подключения в формате `postgres://user:pass@host:port/db`
- 🔐 API Key аутентификация
- 🔑 **Генерация API ключа** — кнопка для создания нового ключа в GUI
- 📋 **Копирование API ключа** — кнопка для копирования ключа в буфер обмена
- 🔒 Шифрование паролей (Fernet)
- 📊 Просмотр таблиц и структуры базы данных
- 📱 Системный трей — сворачивание в трей с контекстным меню
- 📋 Вставка из буфера обмена — поддержка Ctrl+V с учётом позиции курсора
- 📖 Встроенная документация API
- 📝 **Опциональное логирование** — включение/отключение записи логов в файл

## Конфигурация

### Подключение к БД

Настройки подключения в `config/settings.json`:

```json
{
  "database": {
    "host": "localhost",
    "port": 5432,
    "database": "mydb",
    "user": "postgres",
    "password": "secret"
  },
  "api": {
    "host": "127.0.0.1",
    "port": 5000,
    "debug": false,
    "api_keys": ["your-api-key-here"]
  },
  "app": {
    "auto_start_api": true,
    "minimize_to_tray": true,
    "enable_logging": true
  }
}
```

### DSN подключение

Поддерживается подключение через DSN строку в формате:
```
postgres://user:password@localhost:5432/mydb
```

**В GUI:**
- Поле для ввода DSN строки
- Кнопка **"Из DSN"** — автоматически заполняет поля подключения (хост, порт, база данных, пользователь, пароль) из DSN строки

### API Key аутентификация

API ключи **генерируются автоматически** при первом запуске приложения (если не указаны в конфиге). Ключ сохраняется в `config/settings.json`.

Для защиты API добавьте ключи в конфигурацию:
```json
{
  "api": {
    "api_keys": ["key1", "key2"]
  }
}
```

> **Примечание:** Если `api_keys` пустой массив или не указан — аутентификация не требуется.

**В GUI (вкладка "API"):**
- Поле для отображения текущего API ключа
- Кнопка **🔄** — генерация нового случайного ключа
- Кнопка **📋** — копирование текущего ключа в буфер обмена

При запросах передавайте заголовок:
```
X-API-Key: your-api-key-here
```

Проверить статус авторизации: `GET /api/v1/info` → поле `auth_required`

### Режим отладки

В конфигурации `config/settings.json` доступна опция `debug`:
```json
{
  "api": {
    "debug": true
  }
}
```

При `debug: true`:
- Flask отображает детальные сообщения об ошибках с трассировкой стека
- Полезно для разработки и диагностики

> **Внимание:** Не рекомендуется использовать режим отладки в продакшене.

### Опциональное логирование

В конфигурации `config/settings.json` доступна опция `enable_logging`:
```json
{
  "app": {
    "enable_logging": true
  }
}
```

При `enable_logging: true`:
- Логи записываются в файл `app.log`
- При `enable_logging: false` логи записываются только в консоль

> Управлять логированием также можно через GUI на вкладке "API" — переключатель "Ведение логов в файл".

### Шифрование паролей

Пароли автоматически шифруются при сохранении конфигурации. Для дополнительной безопасности можно установить переменную окружения:
```bash
set ENCRYPTION_KEY=your-base64-encoded-key
```

### Системный трей

Приложение поддерживает работу в системном трее:
- При нажатии кнопки **Свернуть** приложение сворачивается в трей
- Иконка в трее отображает статус API (запущен/остановлен)
- Контекстное меню в трее:
  - **Показать окно** — восстановить окно приложения
  - **Запустить API** / **Остановить API** — управление сервером
  - **Выход** — закрыть приложение

### Вставка из буфера обмена

Поддерживается вставка данных через **Ctrl+V**:
- Вставка работает с учётом текущей позиции курсора
- Поддерживается замена выделенного текста
- Работает во всех текстовых полях GUI

## API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/v1/health` | Проверка состояния API |
| GET | `/api/v1/info` | Информация об API |
| GET | `/api/v1/tables` | Список всех таблиц |
| GET | `/api/v1/tables/<name>/columns` | Колонки таблицы |
| GET | `/api/v1/tables/<name>/select` | Выборка из таблицы |
| POST | `/api/v1/tables/<name>/insert` | Вставка данных |
| POST | `/api/v1/query` | Выполнение SQL запроса |

## Примеры использования

### Python
```python
import requests

# Проверка здоровья API
response = requests.get("http://127.0.0.1:5000/api/v1/health")
print(response.json())

# Получить таблицы (с авторизацией)
headers = {"X-API-Key": "your-api-key"}
tables = requests.get("http://127.0.0.1:5000/api/v1/tables", headers=headers).json()
```

### cURL
```bash
# Проверка здоровья
curl http://127.0.0.1:5000/api/v1/health

# Получить таблицы с API ключом
curl -H "X-API-Key: your-api-key" http://127.0.0.1:5000/api/v1/tables
```
